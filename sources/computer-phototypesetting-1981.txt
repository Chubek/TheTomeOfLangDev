Computer phototypesetting
Direct phototypesetting from a
word processing system without
rekeyboarding or reproofing is
possible with the intelligent
communications interface recently
announced by Gestetner, UK.
The programmable word processing interface allows the ICL 7700
information processor to be linked
to the EditWriter system from
Gestetner. ICL have enhanced their
Wordskil software to match the
system.
The interface consists of a single
circuit board which can be installed
in the EditWriter 7300, 7500, 7700,
7770 or 2750. It is designed to
provide flexible communications
and operational capabilities with
99% of all word processors and

computers in current use.
In addition to direct linking, the
interface
can
receive
copy
transmitted over telephone lines.
This allows the EditWriter to be
used as a computer terminal with
the received data stored on discs in
typesetting format.
In the unattended mode the
interface can receive copy during
off-peak hours, when phone rates
are lowest.
The interface does not affect the
normal operation of the phototypesetter. Typographic commands
can be generated on the word
processor or inserted on the
EditWriter. (Gestetner Ltd., 210
Euston Road, London NWl 2DA,
UK. Tel: 01 387 7021, Tx: 28587) []

A multiprocessor device that
enables synchronous and asynchronous communications links to
share access to one or more X.25
network interfaces has been
announced by Symicro, UK.
The unit, known as Microgate,
has been disigned to provide
packet-switched network access
for loosely coupled communications
devices. It will support up to seven
protocol interfaces and up to 28
communications links.
The gateway can operate at
speeds of up to 19.2 kbit/s and
incorporates the
D T S X X.25
processor. The internal architecture
uses intelligent interfacing techniques which allow each protocol
to reside in a discrete communications processor.
Microgate will be upwards
compatible
with
Micronode,
Symicron's local area heirarchical
network which is to be announced
in the near future. It will also be
possible to update the gateway to a
minimal-level Mib Micronode.

Telex interface
A telex interface for the Word
Magic word processing system has
been released by Small Information
Systems, UK.
The configuration allows for
offline editing and storage of telex
messages and timed, unattended
transmission and receive.
Hardware enhancements required include an interface board
and a 10 Mbyte Winchester disc
drive,
essential
for
secure
unattended send and receive. The
disc drive also allows multiscreen
configurations
and
increases
response and capacity.
The complete package includes
a single work station, processor,
printer, interface board and disc
drive. (Small Information Systems
Company Ltd., 4 Moorfields,
London EC2Y 9AA, UK. Tel: 01 920
0315)

Digital control
modules
A series of
microprocessorcontrolled digital control modules
from Robertshaw, USA, is to be
marketed in the UK by Skil
Controls, UK.
The series comprises three basic
modules which can be integrated
within the Robertshaw DCS-1000
distributed control system or can
operate as stand-alone units.
The
DCM-1000
combines
auxiliary
logic,
alarm,
signal
linearization and systems capability
and provides bar-graph display of
process and set-point for accurate
readout.
Operator controls have built-in
digital display for indication of all
operating parameters. Depending
on the alarm, indications are by the
flashing of the bar graph or by an
indicator on the front of the panel.
The controller may be operated in
various modes including proportional plus integral plus derivative
(PID), supervisory PID, direct
digital control with PID backup and
standard PID with ratio.
Three control algorithms are also
included, with a square root
extractor, an adjustable filter for the
process variable and a totalizer.
The DFM-1000 digital function
module can be used alone or with
the
DCS-1000
system
to
implement programmable controller-type logic, typically found in
batch operation. It can function as a
16-point alarm or a 16-point status
indicator.
The AFM-1000 analogue function
module is available in input or
output versions with bar-graph
indicators. The input version can be
used as a stand-alone, four-point
indicator with alarm capability or
with a controller. The output
module, which is designed solely
for use with the DCS-1000 system,
can be used to monitor and display
up to eight values or to output these
values for trend recording. (Skil
Controls Ltd., Greenhey Place, East
Gillibrands, Skelmersdale, Lancs
WN8 9SB, UK. Tel: 0695 23671) []
